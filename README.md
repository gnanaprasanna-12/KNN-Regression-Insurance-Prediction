# KNN Regression – Medical Insurance Cost Prediction

## Project Overview
This project implements the K-Nearest Neighbors (KNN) Regression algorithm to predict medical insurance charges using customer information.

## Dataset
Medical Insurance Cost Dataset.

Target Variable: `charges`

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Implementation Steps
1. Data Loading and Exploration
2. Data Preprocessing
3. Handling Categorical Variables
4. Train-Test Split
5. Feature Scaling using StandardScaler
6. KNN Regression Model Implementation
7. Model Training and Prediction
8. Regression Evaluation Metrics
9. Distance Metric Comparison
10. Prediction on New Data

## Distance Metrics
- Minkowski
- Manhattan
- Chebyshev

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Result
The best-performing distance metric in my initial comparison was Minkowski, with an R² Score of 0.8371.

## Conclusion
This project helped me understand KNN Regression, feature scaling, distance metrics and regression model evaluation.
